# Job Finder

Локальная программа для одного человека. Собирает удалённые IT-вакансии с 13 сайтов в одну базу SQLite и показывает их в браузере: лента с фильтрами, быстрый разбор по одной вакансии, состояние источников.

Источники: Himalayas, RemoteOK, Jobicy, Working Nomads, We Work Remotely, Remote First Jobs, Hacker News «Who is hiring», Arc.dev, Remote Rocketship, Hirify, hh.ru, Хабр Карьера, Getmatch.

## Что нужно

- [uv](https://docs.astral.sh/uv/). Нужный Python uv поставит сам.
- Интернет для сбора. Всё остальное работает без него.

## Установка и запуск

```
uv sync
uv run jobfinder serve
```

Открой http://127.0.0.1:8000. Сервер слушает только этот компьютер.

Через 10 секунд после запуска начнётся первый сбор, дальше он повторяется каждые 6 часов, пока сервер работает. Интервал меняется на странице «Источники». Собрать сразу можно кнопкой «Обновить все» там же.

Первый сбор долгий, около получаса: всё новое, а у hh.ru, Хабр Карьеры, Hirify и Arc.dev программа открывает страницу каждой вакансии за описанием. Следующие сборы короче, потому что берут только новое. Если сайт ограничил доступ (HTTP 429), программа перестаёт к нему обращаться и всё равно сохраняет все найденные вакансии. У части из них не будет полного описания, только то, что было в списке на сайте; полный текст есть по ссылке на оригинал.

## Где лежат данные

База лежит в `data/jobs.db` в папке проекта. Там всё: вакансии, твои статусы, настройки, история сборов.

Чтобы начать с нуля, останови сервер и удали папку `data/`. При следующем запуске база создастся пустой. Статусы и настройки при этом пропадут.

## Токен hh.ru

Без токена hh.ru читается со страницы поиска сайта. Это работает, но ломается, если hh поменяет вёрстку. С токеном программа ходит в официальный API.

1. Зайди на https://dev.hh.ru и войди своим аккаунтом hh.
2. Зарегистрируй приложение в разделе «Мои приложения». Название любое, например «Job Finder личный».
3. Когда приложение одобрят, скопируй токен приложения со страницы приложения.
4. В Job Finder открой «Источники» → «Настройки сбора», вставь токен в поле «Токен hh.ru» и нажми «Сохранить».

Токен хранится в базе, в интерфейсе не показывается. Чтобы убрать его, отметь «очистить токен» и сохрани.

## Команды

```
uv run jobfinder serve [--port 8000]       # веб-интерфейс и сбор по расписанию
uv run jobfinder collect [--source NAME]   # собрать сейчас, все источники или один
uv run jobfinder check-sources [--source NAME]  # проверить сайты вживую, в базу ничего не пишет
uv run jobfinder reparse [--source NAME]   # заново разобрать сохранённые ответы сайтов, без сети
```

У всех команд есть `--db ПУТЬ`, если база нужна не в `data/jobs.db`.

Имена источников для `--source`: `himalayas`, `remoteok`, `jobicy`, `workingnomads`, `wwr`, `remotefirst`, `hn`, `arc`, `rocketship`, `hirify`, `hh`, `habr`, `getmatch`.

`check-sources` берёт по одной странице с каждого сайта и печатает, сколько вакансий нашлось или какая ошибка. Запускай, если источник на «Источниках» стал красным.

`reparse` нужен после обновления программы, если поменялся разбор какого-то сайта: вакансии пересчитаются из сохранённых ответов, сайты заново не опрашиваются. Полные описания, загруженные со страниц вакансий, при этом сохраняются.

## Экраны

**Вакансии.** Слева фильтры: поиск, источники, где можно работать, язык, зарплата от (в долларах в месяц, пересчёт по курсам из кода), свежесть. Справа список и карточка выбранной вакансии со статусами: «Посмотрел», «Интересно», «Откликнулся», «Не подходит». Сверху разделы:

- «Лента» — свежие подходящие вакансии;
- «Мои» — те, что ты отметил «Интересно» или «Откликнулся»;
- «Архив» — вакансии, которые пропали с сайтов или давно висят;
- «Скрытые» — то, что отсеял фильтр (с причиной), и то, что ты отметил «Не подходит».

Поиск понимает синонимы: «питон» найдёт Python, «фронтенд» найдёт frontend, «k8s» найдёт Kubernetes. Стек и грейд ищутся так же, текстом.

**Разбор.** Новые вакансии из ленты по одной. Клавиши: ← не подходит, ↓ позже (станет «Посмотрел»), → интересно. Кнопки на экране делают то же.

**Источники.** Список сайтов с последним запуском: когда, сколько новых, ошибка, если была (такой источник красный). Источник можно выключить. Там же кнопка «Обновить все» и настройки сбора: интервал, свежесть ленты по умолчанию, стоп-слова, токен hh.ru.

## Почему вакансия скрыта

Скрытые вакансии не удаляются. Их видно в разделе «Скрытые», причина написана рядом:

- **гибрид** или **офис** — сайт так указал формат, или в названии и месте работы есть «hybrid», «on-site», «гибрид», «офис»;
- **не IT** — по названию роль не IT: продажи, поддержка, HR, маркетинг, медицина и похожее. С Хабр Карьеры вакансии из разделов продаж, маркетинга, HR и офиса не берутся совсем;
- **не для твоей страны** — вакансия только для США, ЕС или других стран, где нет твоей (по умолчанию Казахстан). Если сайт дал список стран, в нём должна быть твоя: «только Россия» тоже скрывается. «СНГ» в ленте значит, что вакансия открыта для СНГ или для списка стран СНГ с твоей страной;
- **стоп-слово: …** — в названии или описании есть слово из твоего списка стоп-слов. Стоп-слова применяются сразу после сохранения, в том числе к уже собранным вакансиям; если убрать слово, его вакансии вернутся в ленту.

Вакансии, где страна не указана, остаются в ленте с пометкой «уточнить».

Если фильтр ошибся, вакансию всё равно можно открыть из «Скрытых» и поставить ей статус.

## Заметки

- У каждой вакансии есть ссылка на оригинал. Откликаться нужно там.
- Getmatch запрещает в robots.txt доступ к своему `/api/`. Программа делает к нему пару запросов за сбор. Риск принят осознанно, для личного использования.
- Запросы к одному сайту идут строго по одному с паузой 1–2 секунды. Если сайт ответил 429 или 403, программа больше не обращается к нему до следующего сбора.
- Тесты: `uv run pytest -q`. В сеть они не ходят.
