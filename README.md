# Job Finder

Локальная программа для одного человека. Собирает удалённые IT-вакансии с 13 сайтов и из открытых Telegram-каналов в одну базу SQLite и показывает их в браузере: лента с фильтрами, быстрый разбор по одной вакансии, состояние источников.

Источники: Himalayas, RemoteOK, Jobicy, Working Nomads, We Work Remotely, Remote First Jobs, Hacker News «Who is hiring», Arc.dev, Remote Rocketship, Hirify, hh.ru, Хабр Карьера, Getmatch, Telegram-каналы (список меняется на странице «Источники»).

## Установка

Linux или macOS, нужны `git` и `curl`. Скопируй в терминал:

```bash
curl -LsSf https://raw.githubusercontent.com/Postopol/job-finder/main/install.sh | bash
```

Скрипт поставит [uv](https://docs.astral.sh/uv/) (если его нет), скачает программу в `~/job-finder`, поставит зависимости и создаст команду `jobfinder`. Другая папка: `... | JOBFINDER_DIR=~/apps/job-finder bash`.

Скрипт спросит, что ставить:

- **1 — только Job Finder** (сбор вакансий);
- **2 — Job Finder + Resume Studio** — приложение для резюме из папки `resume-studio/`: загрузка и разбор резюме, редактор, PDF, сравнение резюме с вакансией. Job Finder берёт из него резюме для «Профиля». Нужен Node.js 20.9 или новее; скрипт соберёт приложение и создаст команду `resume-studio` (открывается на http://127.0.0.1:3000).

Без вопроса: `... | JOBFINDER_WITH_RESUME_STUDIO=1 bash` (или `=0`). Выбор запоминается: обновление пересобирает Resume Studio, только если он стоит. Поставить его позже — запусти установку снова с `JOBFINDER_WITH_RESUME_STUDIO=1`.

## Обновление

```bash
curl -LsSf https://raw.githubusercontent.com/Postopol/job-finder/main/update.sh | bash
```

База, статусы и настройки остаются. Уже собранные вакансии скрипт пересчитает по новым правилам. Если сервер был запущен, перезапусти его.

## Запуск

```bash
jobfinder serve
```

Если ставил вручную из клона: `uv sync`, потом `uv run jobfinder serve`. Интернет нужен только для сбора.

Открой http://127.0.0.1:8000. Сервер слушает только этот компьютер.

Через 10 секунд после запуска начнётся первый сбор, дальше он повторяется каждые 6 часов, пока сервер работает. Интервал меняется на странице «Источники». Собрать сразу можно кнопкой «Обновить все» там же.

Первый сбор долгий, около получаса: всё новое, а у hh.ru, Хабр Карьеры, Hirify и Arc.dev программа открывает страницу каждой вакансии за описанием. Следующие сборы короче, потому что берут только новое. Если сайт ограничил доступ (HTTP 429), программа перестаёт к нему обращаться и всё равно сохраняет все найденные вакансии. У части из них не будет полного описания, только то, что было в списке на сайте; полный текст есть по ссылке на оригинал.

## Где лежат данные

База лежит в `data/jobs.db` в папке проекта. Там всё: вакансии, твои статусы, настройки, история сборов.

Чтобы начать с нуля, останови сервер и удали папку `data/`. При следующем запуске база создастся пустой. Статусы и настройки при этом пропадут.

## Токен hh.ru

Без токена hh.ru читается со страницы поиска сайта. Это работает, но ломается, если hh поменяет вёрстку. С токеном программа ходит в официальный API.

1. Зайди на https://dev.hh.ru и войди своим аккаунтом hh.
2. Зарегистрируй приложение в разделе «Мои приложения». Название любое, например «Job Finder личный».
3. Когда приложение одобрят, скопируй токен приложения со страницы приложения.
4. В Job Finder открой «Источники» → «Настройки сбора», вставь токен в поле «Токен hh.ru» и нажми «Сохранить».

Токен хранится в базе, в интерфейсе не показывается. Чтобы убрать его, отметь «очистить токен» и сохрани.

## Команды

```
uv run jobfinder serve [--port 8000]       # веб-интерфейс и сбор по расписанию
uv run jobfinder collect [--source NAME]   # собрать сейчас, все источники или один
uv run jobfinder check-sources [--source NAME]  # проверить сайты вживую, в базу ничего не пишет
uv run jobfinder reparse [--source NAME]   # заново разобрать сохранённые ответы сайтов, без сети
```

У всех команд есть `--db ПУТЬ`, если база нужна не в `data/jobs.db`.

Имена источников для `--source`: `himalayas`, `remoteok`, `jobicy`, `workingnomads`, `wwr`, `remotefirst`, `hn`, `arc`, `rocketship`, `hirify`, `hh`, `habr`, `getmatch`, `telegram`.

`check-sources` берёт по одной странице с каждого сайта и печатает, сколько вакансий нашлось или какая ошибка. Запускай, если источник на «Источниках» стал красным.

`reparse` пересчитывает вакансии из сохранённых ответов сайтов по текущим правилам разбора, фильтров и склейки дублей; сайты заново не опрашиваются. `update.sh` запускает его сам после обновления. Полные описания, загруженные со страниц вакансий, сохраняются.

## Экраны

**Вакансии.** Слева фильтры: поиск, источники, где можно работать, язык, зарплата от (в долларах в месяц, пересчёт по курсам из кода), свежесть. Справа список и карточка выбранной вакансии со статусами: «Посмотрел», «Интересно», «Откликнулся», «Не подходит». Сверху разделы:

- «Лента» — свежие подходящие вакансии;
- «Мои» — те, что ты отметил «Интересно» или «Откликнулся»;
- «Архив» — вакансии, которые пропали с сайтов или давно висят;
- «Скрытые» — то, что отсеял фильтр (с причиной), и то, что ты отметил «Не подходит».

Поиск понимает синонимы: «питон» найдёт Python, «фронтенд» найдёт frontend, «k8s» найдёт Kubernetes. Стек и грейд ищутся так же, текстом.

**Разбор.** Новые вакансии из ленты по одной. Клавиши: ← не подходит, ↓ позже (станет «Посмотрел»), → интересно, Enter или O открывает оригинал. Кнопки на экране делают то же.

**Клавиши в «Вакансиях».** ↓ или J — следующая вакансия, ↑ или K — предыдущая, → — «Интересно» и сразу следующая, ← — «Не подходит» и сразу следующая, A — «Откликнулся», Enter или O — открыть оригинал, / — поиск (Esc — выйти из него), 1–4 — Лента, Мои, Архив, Скрытые. Буквы работают и в русской раскладке. Полный список — по клавише ? или кнопке «Клавиши» в углу экрана.

**Источники.** Список сайтов с последним запуском: когда, сколько новых, ошибка, если была (такой источник красный). Под состоянием — качество данных: какая доля вакансий источника без зарплаты, стека и уровня, а у Telegram — сколько постов удалось разобрать. Если источник раньше находил вакансии, а в последний раз не нашёл ни одной, он подсвечивается жёлтым: скорее всего, сайт поменял формат. Источник можно выключить. Там же кнопка «Обновить все» и настройки сбора: интервал, свежесть ленты по умолчанию, стоп-слова, халал-фильтр, токен hh.ru.

## Профиль и Resume Studio

Страница «Профиль» показывает, что Job Finder знает о тебе из резюме: должность, прошлые должности, навыки, опыт в годах, языки. Резюме берётся из Resume Studio (отдельное приложение, по умолчанию http://127.0.0.1:3000) через его API: главное резюме, уже разобранное. Имя и контакты не копируются.

Резюме обновляется кнопкой «Обновить из Resume Studio» и само перед каждым автоматическим сбором, если Resume Studio запущен. Если он выключен, Job Finder работает с последней сохранённой копией. Если в Resume Studio лежит пример (sample-resume.pdf), страница предупредит об этом.

## Telegram-каналы

Программа читает открытую веб-страницу канала `t.me/s/имя`: аккаунт и вход в Telegram не нужны, закрытые каналы так не прочитать. С каждого канала берутся последние посты, при первом сборе — до трёх страниц назад, дальше только новое.

Посты в каналах написаны свободным текстом, поэтому программа разбирает их по шаблону: название в первой строке или в поле «Вакансия:», поля «Компания:», «Формат:», «ЗП:» / «Вилка:», хэштеги вроде #remote и #hybrid. Резюме (#резюме), дайджесты, анонсы митапов, курсов и рекламу она пропускает. Если пост написан совсем без шаблона, у вакансии может не оказаться компании или зарплаты — полный текст и ссылка на пост всё равно есть.

Список каналов — на странице «Источники» в настройках сбора, по одному в строке: имя (`opento_dev`) или ссылка (`https://t.me/opento_dev`). Канал, который не открылся, пропускается, остальные собираются.

## Почему вакансия скрыта

Скрытые вакансии не удаляются. Их видно в разделе «Скрытые», причина написана рядом:

- **гибрид** или **офис** — сайт так указал формат, или в названии и месте работы есть «hybrid», «on-site», «гибрид», «офис»;
- **не IT** — по названию роль не IT: продажи, поддержка, HR, маркетинг, медицина и похожее. С Хабр Карьеры вакансии из разделов продаж, маркетинга, HR и офиса не берутся совсем;
- **не для твоей страны** — вакансия только для США, ЕС или других стран, где нет твоей (по умолчанию Казахстан). Если сайт дал список стран, в нём должна быть твоя: «только Россия» тоже скрывается. «СНГ» в ленте значит, что вакансия открыта для СНГ или для списка стран СНГ с твоей страной;
- **стоп-слово: …** — в названии или описании есть слово из твоего списка стоп-слов. Стоп-слова применяются сразу после сохранения, в том числе к уже собранным вакансиям; если убрать слово, его вакансии вернутся в ленту.

Вакансии, где страна не указана, остаются в ленте с пометкой «уточнить».

Если фильтр ошибся, вакансию всё равно можно открыть из «Скрытых» и поставить ей статус.

## Халал-фильтр

Вакансии из запрещённых сфер не попадают в базу вообще, их нет даже в «Скрытых»:
казино и ставки (включая бинарные опционы и рынки прогнозов), алкоголь, свинина, 18+,
наркотики и каннабис, табак и вейпы, банки, кредиты, МФО и страхование, арбитраж
(трафика, P2P, крипто, статистический), гадания, пирамиды и серые схемы.

Программа смотрит на название компании (чёрный список: 1xBet, Fonbet, Сбер, Т-Банк, Альфа-Банк,
Kaspi и другие), на название вакансии и на однозначные фразы в описании («разрабатываем ПО
для iGaming», «системно значимый банк»). Если запрещённое видно уже в списке на сайте,
страница вакансии не открывается. Отсеянные вакансии запоминаются и не проверяются заново.
Сколько отсеяно за последний сбор, видно на экране «Источники».

Список слов и компаний лежит в `jobfinder/halal.toml`, его можно дополнять. Фильтр
выключается в настройках на экране «Источники». При включении он сразу удаляет из базы
уже собранные запрещённые вакансии, кроме тех, что ты отметил «Интересно» или «Откликнулся».

## Заметки

- У каждой вакансии есть ссылка на оригинал. Откликаться нужно там.
- Getmatch запрещает в robots.txt доступ к своему `/api/`. Программа делает к нему пару запросов за сбор. Риск принят осознанно, для личного использования.
- Запросы к одному сайту идут строго по одному с паузой 1–2 секунды. Если сайт ответил 429 или 403, программа больше не обращается к нему до следующего сбора.
- Тесты: `uv run pytest -q`. В сеть они не ходят.
